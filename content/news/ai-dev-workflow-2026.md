## 원칙

1. **인간이 최종 책임** — 머지와 릴리스 결정은 항상 사람이 합니다.
2. **프롬프트와 맥락 공유** — 이슈 링크·재현 단계를 같이 넣을수록 품질이 올라갑니다.
3. **민감 정보 금지** — 키·개인정보·내부 URL은 절대 입력하지 않습니다.

## 워크플로 예시

```text
이슈 분석 → 작은 단위 작업 쪼개기 → AI 초안 → 로컬 테스트 → PR 설명에 한계 명시
```

## 팀 토론 주제

- 라이선스와 **학습 데이터 정책** 이해
- **자동 생성 코드**의 저작권/기여도 기록 방식
