## 배경

모노레포와 생성 코드가 늘면서 **언어 서비스 메모리·응답 시간**이 병목이 되는 경우가 잦습니다. 5.9에서는 이런 환경을 염두에 둔 최적화와, 일부 엣지 케이스에서의 추론 개선이 강조됩니다.

## 팀에 권장하는 실험

| 항목 | 설명 |
|------|------|
| `tsc --build` | 프로젝트 레퍼런스와 병행 시 증분 빌드 이득 확인 |
| IDE 프로파일링 | 확장 프로그램·워크스페이스 크기 점검 |
| strict 옵션 | 새 코드부터 일관되게 적용 |

```ts
// 예: 판별 유니온에서 추론이 한 단계 덜 깨지는 패턴을 선호
type Result<T> = { ok: true; value: T } | { ok: false; error: string };
```

## 마무리

버전 업 전 **핀포인트 리포지토리**에서 베타를 돌려 보고, 공유 유틸 패키지부터 올리는 순서를 추천합니다.
